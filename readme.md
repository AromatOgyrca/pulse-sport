# PULSE — Система онлайн-записи в спортивный комплекс

Полнофункциональное одностраничное веб-приложение (SPA) с собственным Node.js-сервером и локальной базой данных SQLite для управления расписанием, абонементами и бронированием тренировок в сети спортивных залов **PULSE** (г. Караганда).

## Основные возможности

### Для клиентов

* **Выбор зала по времени суток:** настройка маршрута для утренних тренировок до 15:00 (*PULSE Север*, пр. Бухар-Жырау, 48, `06:00 – 16:00`) и вечерних после 15:00 (*PULSE Центр*, ул. Ерубаева, 15, `14:00 – 00:00`), либо выбор одного зала для всех тренировок.

* **Фильтрация расписания:** живое расписание на 7 дней вперёд (6 слотов в день: `08:00`, `10:00`, `14:00`, `18:00`, `19:30`, `21:00`) с фильтрацией по 5 направлениям (*Силовые и Кроссфит*, *Йога и Пилатес*, *Карате и Бокс*, *Аэробика и Кардио*, *Бассейн и Аква*).

* **Запись на тренировку в 3 шага:**

  1. Выбор зала и тренера.

  2. Выбор способа посещения (активный абонемент за `0 ₸`, разовый визит за `3 500 ₸` или покупка клубной карты).

  3. Оплата через **Kaspi.kz** (с генерацией QR-блока), **Halyk Bank** или банковскую карту **Visa/MC**.

* **Абонементы и клубные карты:** оформление тарифов на 30 дней — `PULSE Start` (`14 900 ₸`), `PULSE Pro` (`22 900 ₸`) и `PULSE VIP` (`34 900 ₸`).

* **Парк тренажёров и инфраструктура (`#/equipment`):** каталог оборудования с точным количеством единиц в залах (беговые дорожки Technogym Run, силовые рамы, гантельные ряды, кроссоверы, гребные тренажёры Concept2, велотренажёры) и описание раздевалок и финской сауны `90°C`.

* **О комплексе и локации (`#/about`):** информация о клубах, контакты регистратуры, быстрое копирование адреса техподдержки и просмотр локаций.

* **Личный кабинет и отзывы (`#/profile`):** просмотр и отмена активных записей, отображение статуса абонемента, редактирование имени и телефона, публикация отзывов с оценкой от 1 до 5 звёзд.

* **Мультиязычность и темы:** мгновенное переключение между тремя языками (**RU** / **KZ** / **EN**) и смена темы оформления (**Светлая** / **Тёмная**).

### Для администратора (`#/admin`)

* **KPI-аналитика:** количество зарегистрированных клиентов, активных записей, процент загрузки залов и доля отменённых бронирований.

* **Управление пользователями:** просмотр списка клиентов, их логинов, тарифов и статусов, заморозка аккаунта на 7 дней и досрочная разморозка.

* **Мониторинг расписания:** сводная таблица всех тренировок на неделю с контролем занятых и свободных мест.

## Технологический стек и библиотеки

* **Frontend:** HTML5, CSS3 (Grid, Flexbox, CSS Variables, адаптивная вёрстка), Vanilla JavaScript (ES6+, Hash Router, встроенный SVG-спрайт).

* **Backend:** Node.js, [Express](https://www.npmjs.com/package/express) (`^5.3.0`), [CORS](https://www.npmjs.com/package/cors) (`^2.8.6`).

* **База данных:** SQLite3 через [better-sqlite3](https://www.npmjs.com/package/better-sqlite3) (`^13.0.3`) в режиме `WAL` с внешними ключами (`foreign_keys = ON`), индексацией и атомарными транзакциями бронирования (защита от овербукинга).

* **Безопасность:**

  * [bcryptjs](https://www.npmjs.com/package/bcryptjs) (`^3.0.3`) для хеширования паролей;

  * [jsonwebtoken](https://www.npmjs.com/package/jsonwebtoken) (`^9.0.3`) для JWT-авторизации (срок жизни токена — 24 часа) с автогенерацией секрета в `.env`;

  * встроенный Rate Limiter (120 запросов/мин с IP глобально и 12 попыток/5 мин на авторизацию, регистрацию и отправку отзывов);

  * закрытая раздача статики (прямой доступ к `pulse.db` и `.env` по HTTP заблокирован).

## Установка и запуск

### Требования

* Установленный **Node.js** версии 18 или выше.

### Пошаговый запуск

1. Откройте терминал в корневой папке проекта и установите зависимости:

   ```
   npm install
   
   ```

2. Запустите сервер одним из способов:

   * **Способ 1 (Windows, в 1 клик):** запустите файл `start.bat` — он автоматически откроет `http://localhost:3000` в браузере и запустит сервер.

   * **Способ 2 (через терминал):** так как в `package.json` не задан блок `scripts`, используйте прямую команду:

     ```
     node server.js
     
     ```

3. Перейдите в браузере по адресу: [**http://localhost:3000**](http://localhost:3000)

> При первом старте сервер автоматически создаст базу данных `pulse.db`, сгенерирует `.env` с ключом `JWT_SECRET`, заполнит тестовые аккаунты, расписание на 7 дней и стартовые отзывы клиентов.

## Архитектура API и базы данных

### API (`POST /api/dispatch`)

Все клиентские запросы отправляются на единый RPC-эндпоинт **`POST /api/dispatch`** с телом `{ "action": "<имя_метода>", "payload": { ... } }` и заголовком `Authorization: Bearer <token>`:

* **Авторизация и профиль:** `auth.register`, `auth.login`, `auth.me`, `profile.update`, `membership.buy`

* **Расписание и бронирование:** `sessions.list`, `booking.create`, `booking.cancel`, `bookings.mine`

* **Отзывы:** `reviews.list`, `reviews.add`

* **Администрирование:** `admin.stats`, `admin.users.list`, `admin.users.freeze`, `admin.users.unfreeze`

### Схема SQLite (`pulse.db`)

База данных состоит из 4 таблиц с каскадным удалением (`ON DELETE CASCADE`) и индексами по дате занятий (`idx_sessions_start`) и статусам бронирований (`idx_bookings_session_status`, `idx_bookings_user_status`):

1. `users` — учётные записи, роли (`user` / `admin`), статус (`active` / `frozen`), сроки заморозки и активные абонементы.

2. `sessions` — слоты расписания (название, категория, тренер, зал, время старта, длительность, вместимость).

3. `bookings` — записи клиентов на тренировки с фиксацией выбранного зала, тренера, тарифа, цены и статуса (`active` / `cancelled`).

4. `reviews` — отзывы пользователей с оценкой (`1–5`) и комментарием.
